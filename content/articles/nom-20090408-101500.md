<h3>どこでも研究室</h3>
<p>研究室の主要ファシリティ(特にメール)にどこからでもアクセスできるようにすべきだと思っています．そのために</p>
<ul>
<li>IMAP や MTP Auth といった近代的なメール環境</li>
<li>SSL によるセキュアな Web アクセス</li>
<li>携帯端末に優しい Web コンテンツ</li>
</ul>
<p>を検討すべきでしょう．Zimbra の実用も視野に入れて．</p>
<h3>実験環境の充実</h3>
<p>これはいうまでもなく，vmserver の本格運用を期待しています．</p>
<ul>
<li>vmserver の安定した稼働体制</li>
<li>Redmine を利用したワークフローの整備</li>
</ul>
<h3>実験プロダクトの実戦投入</h3>
<p>主に GN の成果である以下のプログラムを常用に漕ぎ着けるべきでしょう．
やはり，作ったものは使わないと意味がありません．そういう風土を作っていく上で，実戦投入は，利便性の向上だけではない意味があります．</p>
<ul>
<li>MLサーバ</li>
<li>デスクトップブックマーク</li>
<li>Zimbra 日本語環境</li>
<li>CMDB の新バージョン</li>
</ul>

<ul>
<li>Darwin Calendar Server</li>
<li>DAViCal</li>
<li>Google Calendar</li>
</ul>
<p>クライアントとして，</p>
<ul>

</ul>
