Yesodでのnomnichi開発の促進のため，<br>Mac OSX Mavericks向けにYesodでnomnichiを立ち上げるための方法を書きます．<br><br>
<b>Haskell＆Yesod アンインストール</b><span style="font:13.0px Arial"></span><br><span style="font:13.0px Arial"><pre># インストールされているHaskell-platformのバージョンを確認<br>$ sudo uninstall-hs<br><br># バージョンを指定してアンインストール(7.4.2の場合)<br>$ <span style="font:13.0px Arial">sudo uninstall-hs --remove only 7.4.2 </span>
<br># cabalを削除<br>$ rm -rf ~/.cabal<br>$ rm -rf ~/.ghc<br></pre></span>
<b><br>Haskellインストール<br></b><span style="font:13.0px Arial"></span>
<pre># https://www.haskell.org/platform/mac.html<br># 上記URLの<strong>Xcode 5 &amp; OS X 10.9 (Mavericks)</strong>の項にある<a href="https://www.haskell.org/platform/ghc-clang-wrapper">ghc-clang-wrapper</a>というbash scriptを/usr/bin以下にコピーし，実行権限を与えsudoで実行<br># 上記URLからMac版の最新Haskell-Platformをダウンロード＆インストール<br></pre>

<br><b>Yesodインストール</b>(既存Yesodプロジェクトがある場合)<br>
<pre># cabalのもつリストをアップデート<br>$ cabal update<br><br># cabal自身のインストール（アップデート）<br>$ cabal install cabal-install<br><br># 新たなcabalにPATHを通す<br>$ echo PATH=$HOME/Library/Haskell/ghc-7.6.3/lib/cabal-install-1.18.0.3/bin:$PATH &gt;&gt; ~/.bashrc<br><br># Yesodプロジェクトのディレクトリに移動<br>$ cd Yesod/Project/path<br><br># プロジェクトのディレクトリ以下にsandboxを作成<br># これにより，以降のcabal installコマンドはsandboxの中にインストールされる<br>$ cabal sandbox init<br><br># インストール<br>$ cabal install

# コマンドをインストール
$ cabal install yesod-bin<br><br># sandboxの環境にPATHを通す<br>$ echo PATH=$HOME/Dropbox/Nomlab/home/admin/misc/nomnichi/.cabal-sandbox/bin:$PATH &gt;&gt; ~/.bashrc<br><br># 立ち上げてみる<br>$ yesod devel<br></pre>
