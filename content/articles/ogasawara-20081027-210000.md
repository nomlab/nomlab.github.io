<p>デスクトップブックマークをRails 2.1.1 対応にしました！意外に簡単にアップできたので，メモを以下に残しておきます．</p>
<p><!-- folding --></p>
<p>(1) Rails2.1.1をインストールする</p>
<ul>
<li># gem install rails --version=2.1.1</li>
</ul>
<p>(2) プロジェクトの作成</p>
<ul>
<li># rails DesktopBookmark</li>
</ul>
<p>(3) 既存ファイルのコピー</p>
<ul>
<li>/app 以下</li>
<li>/db/migrate 以下</li>
<li>/lib 以下</li>
<li>/public/explication 以下</li>
<li>/public/images 以下</li>
<li>/public/stylesheets 以下</li>
<li>/ 以下</li>
</ul>
<p>(4) PaginateがRails2.0にはありません！</p>
<p>以下を参考にして解決．</p>
<p><a href='http://d.hatena.ne.jp/hayori/20080418/1208490669'>http://d.hatena.ne.jp/hayori/20080418/1208490669</a>
<a href='http://brass.to/blog/will_paginate.html'>http://brass.to/blog/will_paginate.html</a></p>
<ul>
<li># gem install will_paginate</li>
</ul>
<p>その後，コントローラに以下の記述を追加するとよい．</p>
<ul>
<li>require 'will_paginate'</li>
</ul>
<p>(5) start_form_tagがRails2.0にはありません！</p>
<p>以下を参考にして解決．</p>
<p><a href='http://d.hatena.ne.jp/dreammind/20071228'>http://d.hatena.ne.jp/dreammind/20071228</a></p>
<p>正解</p>
<pre>&lt;% form_tag :action =&gt; 'update', :id =&gt; @foo do %&gt;
  &lt;%= submit_tag 'Edit' %&gt;
&lt;% end %&gt;</pre>
<p>不正解</p>
<pre>&lt;%= start_form_tag :action=&gt;'update', :id=&gt;@foo %&gt;
  &lt;%= submit_tag 'Edit' %&gt;
&lt;%= end_form_tag %&gt;</pre>
