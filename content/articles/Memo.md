<p>最近，アイデアや思いつきを上手く管理する方法について試行錯誤しています．
今回は自分がやっている方法をいくつか紹介したいと思います．</p>
<p>ちなみに，前提として以下の3つがあります．</p>
<p>(1)できればメモはEverNoteに集約したい．
(2)いつでもどこでもメモしたい．
(3)持っているスマートフォンはAndroid</p>
<p><!-- folding --></p>
<p>(1)手書き-&gt;ドキュメントリーダー-&gt;EverNote</p>
<p>[利点]</p>
<ul>
<li>表現の方法が自由</li>
<li>アイデアの整理しやすい</li>
</ul>
<p>[欠点]</p>
<ul>
<li>文字データとして扱いづらい</li>
<li>データ化した後，整理のための後処理が大変</li>
<li>データ化した後修正が難しい</li>
</ul>
<p>まず一番一般的なメモ収集だと思われる方法．</p>
<p>利点としては，紙に自由に記述できるので，図や文字を駆使してアイデアを整理しやすいこと．
よって，落ち着いたところで思考を深めていくにはベストな方法だと思われます．</p>
<p>欠点としては，データ化した後管理が難しいこと．
OCRを使ってもなかなかメモを正しく読み取ってくれません．
よって，EverNoteに入れた後，全文検索に引っ掛けるために，いろいろ付加情報を追加することが必要です．
また，ドキュメントリーダーにかけるのがめんどくさく，思いついた時刻とデータの時刻がずれてしますことが頻発．
さらに，画像やPDFにしてしまうと後からメモを加筆すること難しい点もマイナス．</p>
<p>(2)AndroidのEverNoteアプリ-&gt;EverNote</p>
<p>[利点]</p>
<ul>
<li>　一行メモが最速</li>
<li>文字列として扱いやすい</li>
</ul>
<p>[欠点]</p>
<ul>
<li>思考を深めづらい</li>
<li>あとから見た時の見栄えが悪い</li>
</ul>
<p>EverNoteのメモ収集では，多分一般的だと思われる方法．
1行2行のメモをするなら，これが一番手軽で良いかと．
音声を文字列に変えてEverNoteアプリに入れるという方法もありますが，試したところ精度が悪く，手入力の方が早いという結論に．
あと，表現方法が文字列のみなので，思考を深めるのには適しません．</p>
<p>(3)AndroidのMindMapMemo-&gt;FreeMind-&gt;EverNote</p>
<p>[利点]</p>
<ul>
<li>頭の中を整理しやすい</li>
<li>手軽にどこでも使える</li>
</ul>
<p>[欠点]</p>
<ul>
<li>EverNoteに入れるまでが手間</li>
</ul>
<p>個人的におすすめしたい組み合わせ．
手軽さと思考の深めやすさのバランスがいい．
電車の中とかで，頭の中を整理したいと思ったときに◎．
MindMapMemoに画像での保存機能をつけば，FreeMindを通す必要がなくなるので，すごく便利になるのになあ．</p>
<p>(番外編)AndroidのWikiMind-&gt;?wiki2html-&gt;?EverNote</p>
<p>[利点]</p>
<ul>
<li>　手軽にどこでも使える</li>
<li>見栄えが良い</li>
<li>比較的大量の情報でもまとめられる</li>
</ul>
<p>[欠点]</p>
<ul>
<li>EverNoteとの連携が上手くいかない</li>
</ul>
<p>上手く行けばいいなと思いつつ試行錯誤中している組み合わせ．
wiki2htmlが上手く通らないやら，そもそもwiki2htmlにかけるのがめんどくさいやら．
ただ，WikiMindはwiki記法を手軽に書ける良いエディタです．
また，後から見た時の見栄えが良い．
さらに，wiki記法ならば，(2)(3)の方法と比べて比較的大量の情報を整理して記述できます．
wiki記法とEverNoteの相性が悪いところが問題．</p>
