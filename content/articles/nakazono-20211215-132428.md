こんにちは．乃村研M2の中園です．
今回は12/2(木)に研究室のみんなでコーディング会を行いました．
<!-- folding -->
乃村研では，皆が集まって各自もくもくと勉強したり，もくもくと作業したりする会もあれば，今回のように1つのアプリケーションを開発したりすることもあります．
前回の様子は[こちら](http://www.swlab.cs.okayama-u.ac.jp/lab/nom/articles/nishi-20190717-174742) ．

今回のお題は，現在乃村研で開発中の Rask という Todo 管理アプリの開発作業です．
GitHub のリポジトリは[こちら](https://github.com/nomlab/rask)にあるので，気になった方はのぞいてみてください．

以下が今回開発で取り組んだ内容の一覧です．
* 見た目(フロント)
  * マークダウンの CSS を作る
  * 議事録，Task，project の一覧画面を整える
* 動作
  * 議事録から Task の登録，GitHub の issue の登録を行う
  * テスト用アカウントを作る
* インフラ
  * Linux のインストールとセットアップ
  * Docker で Rask を動作させる
  * Network に登録する
  * Jay から Rask にデータ移行する

3グループに分かれてそれぞれ見た目，動作，インフラの作業を担当しました．
![whiteboard.jpg](https://pinatra.nomlab.org/photo/AJGjcU8kzUqtFtxnAvxTatr38xZX3msJeEB4mrTYdFGRAj_4E9apPcCoNrGH2ljFDnY0qitkHKNNZBRoBK8pJUcDVnMO4F2hxg.jpg){:width="300px" class="photo"}
私はM2の坂本くん，M1の松田くん，B4の向原くんと一緒に動作関係のタスクに取り組みました．

今回は，要件定義の話をしたり，関連するソフトウェアのコードリーディングを行っただけで時間が過ぎてしまいました．
![議論の結果.jpg](https://pinatra.nomlab.org/photo/AJGjcU8-OOCpOFjg4CtiVbF04EIRoviydV0CcVTEBILGkB8AxbIMLrQx7LqvW9DaoGsViLphY3W2atCq2vrWPx8MC-7XDKBJ0A.jpg){:width="300px" class="photo"}
しかし，今後取り組むべきタスクがより明確になったので今後の開発がやりやすくなったと思います！
Rask を実用する日に一歩近付いたと思います．
