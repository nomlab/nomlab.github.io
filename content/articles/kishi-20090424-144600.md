<p>4月23日に Ubuntu 9.04 がリリースされました．</p>
<p><!-- folding --></p>
<p>開発コード名は「Jaunty Jackalope」で，「軽快なツノウサギ」という意味です．</p>
<p>9.04 では，起動時間の短縮に重点が置かれており，実際に起動時間が速くなったという報告も見られます．</p>
<p>私は，CeleronM 1.73GHz，メモリ 1.5GB の Windows XP で VMWare 上にUbuntu 9.04 をインストールしてみました．8.04 に比べると，確かに起動が速くなったような気がします．また，起動時間だけではなく，アプリケーションの起動や動作も速く軽くなっているようです．私の上記スペック PC では，8.04 は重たくて使い物にならなかったのですが，9.04 はストレスなく使用できるほどです．</p>
<p>カーネルは 2.6.28． X Window System には X.Org プロジェクトの xserver 1.6 を，デスクトップ環境には GNOME 2.26 を採用しています．</p>
<p>まだインストールしたてなので，しばらく遊んでみようと思います．</p>
