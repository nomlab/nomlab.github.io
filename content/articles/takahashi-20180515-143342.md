はじめまして，乃村研究室B4の高橋 桃花です．4月から研究室配属となりました．
5/11(金)にB4，M1，M2の石川さんと「GitHub Patchwork Okayama 2018」というイベントに参加してきました．
<!-- folding -->
[GitHub Patchwork](http://patchwork.github.io/)は，git や GitHub の使い方を学びたい初心者のためのハンズオンワークショップです．
ワークショップを通して個々のペースでチュートリアルを進めて行き，git や GitHub の使い方を学んでいきます．
分からないことがあればメンターの方に質問できるので，初心者でも安心して参加できるイベントです．

イベント参加者は30人ほどで，美味しいケータリングもありました．
学生から社会人まで，色んな方が参加されていました．会場の雰囲気はこんな感じです．

まずはじめに，GitHub の社員の方からご挨拶があり，オープンソースに関するビデオを見ました．
その後，湊川あいさんという，漫画家兼Webデザイナーの方から，GitHub やオープンソースについてのお話がありました．
湊川さんは，漫画編集を GitHub 上で行っているそうです！
お話を聞いた後は各自チュートリアルを進めていきました．

イベント終盤に，M2の石川さん，M1の山本さん，私で，研究室での GitHub の使用事例について発表しました．
事前にしっかり準備をしていたので，特に緊張することなく発表できました！
