<p>MacにYesodを入れる手順を覚えてる範囲で書きます．</p>
<p><!-- folding --></p>
<p>１．Haskell Platformをインストールする．<a href='http://hackage.haskell.org/platform/'>http://hackage.haskell.org/platform/</a> Haskellが使えるようになるとともに，cabalが使えるようになります．
ついでにupdate．</p>
<pre>       $ cabal update</pre>
<p>２．Yesod Platformをインストールする．</p>
<pre>       $ cabal install yesod-platform</pre>
<p>３．パスを通す．
.bash_profile とかに以下の1行を追加．</p>
<pre>       export PATH=$HOME/Library/Haskell/bin:$PATH</pre>
<p>追加したら，読み込み直します．</p>
<p>これでインストール完了．．．だと良いんですが，自分は途中で詰まりました．
というのが，yesod-platformのインストールがうまくいきませんでした．
原因は，gccが入っていないことだった気がします．
新しいxcodeには，gccではなくllvm-gccが入っており，gccとの互換性が無い部分もあるそうです．
なので，yesod-platformのインストールで失敗した人は入れてみるといいかもしれません．</p>
<hr>
<p>インストールできたら，試しに使ってみます．</p>
<pre>       $ yesod init</pre>
<p>で，プロジェクト名なんかを聞かれるので，言われるがままに進めます．
作成されたディレクトリに移動して，</p>
<pre>       $ cabal install
       $ yesod devel</pre>
<p>で，起動して<a href='http://localhost:3000'>http://localhost:3000</a> にアクセスします．</p>
<p>で，開けばいいんですが．．．自分は途中で詰まりました．</p>
<pre>       $ yesod devel</pre>
<p>をした際に，Exit Failure 11 が出ます．
これはSegmentation Fault を意味するらしいです．
Macでは皆同じエラーが出るっぽいので，自分が考えた案を書きます．</p>
<p>1.gdbを使う</p>
<p>2.VMを使う．kawasemiとか．</p>
<p>3.32bit版のHaskellPlatformを使う</p>
<p>4.Windowsでやる</p>
<p>5.待つ</p>
<p>もっとスマートに解決する方法があれば教えてください．</p>
