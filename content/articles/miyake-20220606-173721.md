こんにちは，(自称) Vimmer の三宅です．
本日は Vim の良さを紹介したいと思います．

<!-- folding -->

この記事を読んでくださっている皆様は，何をメインエディタとして使っていますか？
多くの方は，初めから優秀な設定が入っており，拡張機能も優秀なものが多い VSCode と答えるのではないでしょうか．
しかしVSCodeは ssh 先で使えなかったり，インストールが地味に面倒くさかったりします．

そんな時におすすめなのが Vim です．
Vim はターミナル上で動作する軽量なエディタで，最小の手の動きで編集できる操作方法になっていることが特徴です．
ネットでは，初日には編集はおろか，閉じ方すらわからないことで有名ですが，一度キーマップを覚えればこれほど素早く操作できるエディタはありません (当社調べ)．

また，VSCode の拡張機能に当たる Plugin というものがあり，Plugin を導入することで様々な機能を追加することができます．
私が特におすすめするのが Language Server Protocol (LSP) の Plugin です．
こんなふうにエラーを表示したり，メソッドや変数の補完をしてくれたりします．
