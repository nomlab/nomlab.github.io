<p>10月3日(土)に第10回乃村研勉強会を行いました．
テーマはバージョンコントロールシステム「Git」です．
Git は，Linux や Ruby on Rails のバージョン管理に使われているので，
今後，研究室の全員が関わる必要のあるシステムです．</p>
<p><!-- folding -->
今回はゲストとして乃村研卒業生の岸さんと，
谷口研の学生3人も参加して，
計14人という大規模な勉強会になりました．</p>
<p>課題図書：
<a href='http://www.amazon.co.jp/gp/product/0596520123/'>http://www.amazon.co.jp/gp/product/0596520123/</a></p>
<p>当初の予定では，勉強会後半にGitをいろいろ触ってみるつもりだったんですが，
スライド発表が長引き，残念ながらGitを使うのは今後の課題ということに．
ですが，その分スライドを使ってGitのコンセプトや内部構造を深く理解できたと思います．</p>

<p>打ち上げは焼肉食べ放題の店に行きました．
ただ写真を撮るのを忘れていたので残念ながら写真はありません．</p>
