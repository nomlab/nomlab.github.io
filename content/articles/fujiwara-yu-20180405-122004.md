はじめまして，乃村研究室 B4 の藤原 裕貴です．4月から研究室配属となりました．<br>
新人研修の一環として，4月3日と4日に勉強会を開いていただきました．
内容は，Web システムについてと git(GitHub) についてでした．<br>

<!-- folding -->
初日は，Web の仕組みとサービス構築で使われる技術について学びました．
例えば，Slack とのサービス連携で使われる WebHook の仕組みと PaaS サービスである Heroku について学びました．
その後，実際に手を動かしながら，rbenv を使った Ruby のインストール方法と使用方法を学びました．<br>

二日目は，git と Github について学びました．どちらもこれから研究でよく使うため，半日かけてじっくり教えていただきました．

Web と rbenv については先輩方の丁寧な説明のおかげですんなりと理解することができました．
勉強会後に実際に自分の計算機に rbenv をインストールし，動作確認ができました．
git の説明は先輩方と先生のおかげでなんとか理解できました．
しかし，実際に使ってみると思っていたよりも難しく，先輩の助言を借りなければ扱えませんでした．<br>

どちらも研究に必要なため，早く慣れていきたいです．
