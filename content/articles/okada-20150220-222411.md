<h2>はじめに</h2>
みなさんこんにちは．岡田です．<br>
<a href="http://getbootstrap.com/">Twitter Bootstrap</a>，綺麗ですよね．<br>
class をちょっといじるだけでおしゃれサイトが簡単につくれます．<br>
そんな Twitter Bootstrap を Rails で簡単に使う gem に
<a href="https://github.com/seyhunak/twitter-bootstrap-rails">seyhunak/twitter-bootstrap-rails</a>
があります．<br>
本記事では，上記 gem において Twitter Bootstrap の icon(Glyphicons) が使えない問題への対処について述べます．<br><br>
<!-- folding -->

<h2>結論</h2>
以下の<strong>iconが表示されない</strong>コードを<br>
<pre>
&lt;span class=&quot;<strong>glyphicon glyphicon</strong>-search&quot;&gt;&lt;/span&gt;
</pre>
こうします．
<pre>
&lt;span class=&quot;<strong>fa fa</strong>-search&quot;&gt;&lt;/span&gt;
</pre><br>

<h2>理由</h2>
<a href="https://github.com/seyhunak/twitter-bootstrap-rails#icons">seyhunak/twitter-bootstrap-rails では default の icon を
Font Awesome にしているため</a>です． <br>
なので，結論に書いたようにそのまま class 要素を書き換えたのではでない icon もあります．<br>
<a href>Glyphicons と Font Awesome の各 class に対応する icon の一覧を紹介したページ</a>がありますので，<br>
こちらを参考にして欲しい icon を探しましょう．<br><br>
