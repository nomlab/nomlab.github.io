こんにちは，M1の三宅です．9月22日に第42回乃村杯を行いました．

<!-- folding -->

普段はゲームやスポーツを行うことが多い乃村杯ですが，今回は幹事である私の意向によりクイズ大会を行いました．
ですが普通のクイズではなく，回答側が「3人1チームで10分間何でもありで調査可能 (インターネットもあり) 」という条件．
一人一題の出題でしたが，この条件のおかげで皆さん非常に難しい問題が多かったです．

実際の問題を見ていきましょう．

+ B4木村くんの問題です．
```
次のBefungeで書かれたプログラムは，2つの自然数を入力とする．このプログラムは何を求めるプログラムか答えなさい．
v >0g\v@.<
>#0 &&>:v$
^%p00:_^
```
10分間で知らない言語 (しかも難読) の解読を行わなければならないというなかなか大変な問題です．

+ M2坂本さんの問題です．
```
LastNoteにおいて，2014年に乃村先生以外がコミットした回数を答えよ
```
一見単純そうですが，まともに数えていてはとても時間が足りない．
こちらはシェルや Git を駆使して正解を見つけなければならない情報系らしい問題です．

+ 拙作ですが，私，M1三宅の問題です．
```
下の画像に隠された暗号を解き，答えとなる単語を見つけ出せ
```
![crypt.jpg](https://pinatra.nomlab.org/photo/AJGjcU9UDHgPYnvB_hdUoV_5AbiqPAbc6Dc6z6Y7Jlvsda_H3mNY25XQnRpG2Y0ooLwo-mnKWEeXJK7k7lPeIFVGnamFeESnWQ.jpg){:width="300px" class="photo"}
YouTube で知った，画像に暗号を隠す方法を自分で真似て作ってみた暗号問題です．

3問だけ見てみましたが，それでもなかなかの難易度ですね．
もし，答えがわかったという方はぜひコメントでお知らせ下さい．

乃村杯の結果としては，田井くん，中川くん，濵本さんのチームが優勝，向原くん，松田くん，松尾さんのチームが最下位，もとい次回幹事となりました．
普段の乃村杯と違った様相となりましたが，創意工夫を凝らして問題を作ったり，チームで議論しながら問題を解いたりと非常に楽しかったです．
