<p>vim 上での LaTeX 入力支援環境である、vim-latex。
<!-- folding -->
以下の URL からダウンロードできます。</p>
<p><a href='http://vim-latex.sourceforge.net/index.php?subject=download&amp;title=Download'>http://vim-latex.sourceforge.net/index.php?subject=download&amp;title=Download</a></p>
<p>アーカイブを $VIM/vimfiles 以下に展開します。そして、 _gvimrc に以下を追記します。</p>
<pre>' -------------------
' vim-latex
' -------------------
set shellslash

' dviファイル生成
let g:Tex_CompileRule_dvi = 'platex --interaction=nonstopmode $*'
let g:Tex_ViewRule_dvi = 'C:\Users\ogasawara\software\tex\dviout\dviout.exe' 

' pdf生成
let g:Tex_DefaultTargetFormat='pdf'
let g:Tex_CompileRule_pdf = 'dvipdfmx $*.dvi'
let g:Tex_FormatDependency_pdf = 'dvi,pdf'
let g:Tex_ViewRule_pdf = 'C:\Program Files\Adobe\Reader 9.0\Reader\AcroRd32.exe' 

' jbitex設定
let g:Tex_BibtexFlavor = 'jbibtex -kanji=sjis'</pre>
<p>これにより、.tex 拡張子のついたファイルを開くと、自動的に LaTeX-Suite 機能が発動します。</p>
<p><a href='http://vim-latex.sourceforge.net/documentation/latex-suite-quickstart.html'>http://vim-latex.sourceforge.net/documentation/latex-suite-quickstart.html</a></p>
<p>簡単な使いかた：</p>
<pre>\ll : 指定したコマンドでコンパイル (tex -&gt; dvi =&gt; pdf ファイルへ)
\lv : 指定したビューワで pdf ファイルを閲覧</pre>
