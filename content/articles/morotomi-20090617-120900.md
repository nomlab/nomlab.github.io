<p>IE8がCSS3に対応した，という記事を見かけたので，CSS3について調べてみました．</p>
<p><!-- folding --></p>
<p>色々と効果があるんですね．テキストに影をつけたり，コーナーを丸くしたり．
透明度なんかも指定できるらしいです．</p>
<p>これで，凝ったデザインのページが作成できますね．
特に，透明度の設定なんかが面白そうです．</p>
<pre>h1{
	text-shadow : 4px 4px 10px black;
}


h1 {
	width:300px;
	height:300px;
	border:2px solid blue;
	-webkit-border-radius:10px;
	-moz-border-radius: 10px;
}


h1 {
	width:300px;
	height:300px;
	background:red;
	opacity:0.5;
}</pre>
