<p>Debianでyesodをインストールする手順について書きます．</p>
<p><!-- folding --></p>
<p>1．パッケージを入れる</p>
<p>libglut3-dev，libgmp3-devの２つのパッケージが入っていない場合，以下の手順で入れます．</p>
<pre>       $ sudo aptitude install libglut3-dev
       $ sudo aptitude install libgmp3-dev</pre>
<p>2. GHCのインストール</p>
<p>以下の手順でGHCのインストールを行います．</p>
<pre>       $ wget http://www.haskell.org/ghc/dist/7.4.1/ghc-7.4.1-i386-unknown-linux.tar.bz2
       $ tar xvzf ghc-7.4.1-i386-unknown-linux.tar.bz2
       $ cd ghc-7.4.1
       $ ./configure
       $ sudo make install</pre>
<p>3. Haskell Platformのインストール</p>
<p>以下の手順でHaskell Platformのインストールを行います．</p>
<pre>       $ wget http://lambda.haskell.org/platform/download/2012.2.0.0/haskell-platform-2012.2.0.0.tar.gz
       $ tar xvzf haskell-platform-2012.2.0.0.tar.gz
       $ cd haskell-platform-2012.2.0.0
       $ ./configure
       $ make
       $ sudo make install</pre>
<p>4. yesodのインストール</p>
<p>以下の手順でyesodのインストールを行います．</p>
<pre>       $ cabal update
       $ cabal install yesod-platform</pre>
<p>次に.bash_profileに以下の1行を追加してパスを通します．</p>
<pre>       export PATH=$PATH:$HOME/.cabal/bin</pre>
<p>以上でyesodのインストールが完了します．</p>
<hr>
<p>kawasemi(VM)で手順3まで実行しているので，各自のアカウントで手順4を実行するとyesodが使えるようになります．インストールには15分くらいかかります．</p>
