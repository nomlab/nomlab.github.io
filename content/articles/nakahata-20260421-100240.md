写真は Git 勉強会と乃村研究室内製ツール勉強会の様子です．

Git はブランチへの操作をあまり行ったことがなかったので，勉強会を通して仕組みや使い方について理解が深まりました．

乃村研究室内製ツール勉強会では Rask，swimmyなどについて勉強しました．Rask はタスクや文書を管理する内製ツールで，swimmy は Slack 上で動くチャットボットです． swimmy は Web Socket を用いた Events API を利用しています．

4月21日現在，Rask の API を使用したプログラムと swimmy の連携を行っているのですが，これらの勉強会で学んだことはとても役立っています．

これらの勉強会で学んだことを，今後の活動にも活かしていきたいと思います．
