### 研究テーマ

**テーマ:**  
カレンダ情報を操作可能なローコードシステム

**概要:**  
Googleカレンダーをはじめとする既存のカレンダシステムは，業務やプライベートを問わず広く利用されている．
しかし，既存のシステムは主にリマインダとしての利用を想定しており，蓄積された予定を再利用可能なデータとして集計，加工，共有するなどの高度な操作には適していない．高度な操作には Application Programming Interface (API) を用いたプログラミングが必要となるが，プログラミング経験のない一般ユーザにとって，APIを利用したプログラム作成は困難である．
そこで本研究では，カレンダ情報をデータベースとして捉え，GUI 上でのブロック操作を通じてデータ操作が可能なローコードシステムを提案する．
本システムは，Blocklyを用いてブロックベースのインタフェースを実装し，ユーザが作成したブロックをJavaScriptコードに変換して実行することで，カレンダデータの操作を実現する．
初期実装による評価では，専門知識のないユーザでもある程度の操作が可能となった一方で，型の不一致や破壊的操作の誤認といったユーザインタフェース上の課題が明らかになった．そこで本研究では，さらにこれらの課題を解決するための編集支援機能と Large Language Model (LLM) を用いた対話型アシスタントを実装し，ユーザが対話的にプログラミングできる環境を実現する．
